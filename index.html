Desenvolvimento com teclado

Entenda a diferença entre caracteres ASCII e códigos físicos de teclas.

Conceito fundamental: asciiKey representa o caractere produzido pela tecla. ps2key representa o código da tecla recebido pelo driver. Uma tecla especial pode não produzir nenhum caractere ASCII.

1. Lendo caracteres

PS2KeyboardInfo kbd;

while (1) {
    ReadPS2();
    GetKeyboardInfo(&kbd);

    if (kbd.asciiKey != 0) {
        // Existe um caractere para processar
        putchar(kbd.asciiKey);
    }
}

2. Identificando teclas especiais

Para identificar uma tecla física, utilize ps2key, não asciiKey. 

if (kbd.ps2key == 0xE048) {
    // Seta para cima
}

if (kbd.ps2key == 0xE050) {
    // Seta para baixo
}

if (kbd.ps2key == 0xE04B) {
    // Seta para esquerda
}

if (kbd.ps2key == 0xE04D) {
    // Seta para direita
}

3. Tabela das setas

Tecla Scancode de 16 bits
↑ Cima0xE048
↓ Baixo0xE050
← Esquerda0xE04B
→ Direita0xE04D
Os códigos acima consideram Scan Code Set 1 e a representação de 16 bits em que E0 ocupa o byte superior. A comparação depende de o driver preservar o prefixo estendido em ps2key.

4. Exemplo: movimentação de personagem

if (kbd.keyPress) {
    switch (kbd.ps2key) {
        case 0xE048:
            player_y--;
            break;

        case 0xE050:
            player_y++;
            break;

        case 0xE04B:
            player_x--;
            break;

        case 0xE04D:
            player_x++;
            break;
    }
}

5. Identificando letras

if (kbd.asciiKey == 'a') {
    // Letra A
}

if (kbd.asciiKey == 'z') {
    // Letra Z
}

6. Modificadores

if (kbd.mod.CTRL_ON) {
    // Ctrl pressionado
}

if (kbd.mod.SHIFT_ON) {
    // Shift pressionado
}

if (kbd.mod.CAPS_ON) {
    // Caps Lock ativado
}

if (kbd.mod.ALT_ON) {
    // Alt pressionado
}

if (kbd.mod.ALTGR_ON) {
    // AltGr pressionado
}

7. Teclas mortas

Teclas de acentuação podem aguardar a próxima tecla para formar um caractere composto.

Desenvolvimento com mouse

Receba informações de movimento, botões e roda de rolagem para desenvolver interfaces gráficas.

1. Obtendo informações

PS2MouseInfo mouse;

ReadPS2();
GetMouseInfo(&mouse);

2. Campos do mouse

Campo Descrição
mouse.xMovimento horizontal.
mouse.yMovimento vertical.
mouse.scrollMovimento da roda.
mouse.leftEstado do botão esquerdo.
mouse.rightEstado do botão direito.
mouse.middleEstado do botão central.
mouse.packetReadyIndica pacote recebido.

3. Movimentando o cursor

PS2MouseInfo mouse;

while (1) {
    ReadPS2();
    GetMouseInfo(&mouse);

    if (mouse.packetReady) {
        cursor_x += mouse.x;
        cursor_y += mouse.y;

        // Atualizar o cursor na tela
    }
}

4. Detectando os botões

if (mouse.left) {
    // Botão esquerdo pressionado
}

if (mouse.right) {
    // Botão direito pressionado
}

if (mouse.middle) {
    // Botão central pressionado
}

5. Utilizando a roda

if (mouse.scroll > 0) {
    // Rolagem para cima
}

if (mouse.scroll < 0) {
    // Rolagem para baixo
}

6. Exemplo de interface gráfica

if (mouse.packetReady) {

    cursor_x += mouse.x;
    cursor_y += mouse.y;

    if (mouse.left) {
        // Verificar clique em algum componente
    }

    if (mouse.right) {
        // Abrir menu de contexto
    }

    if (mouse.scroll != 0) {
        // Atualizar posição da rolagem
    }
}
Os nomes dos campos e os tipos devem corresponder exatamente às estruturas declaradas na versão de ps2.h utilizada. A disponibilidade da roda depende do modo negociado com o mouse.

Ajuda e desenvolvimento

Recomendações para integrar a biblioteca ao seu sistema.

Polling

Chame ReadPS2() frequentemente para processar os bytes recebidos dos dispositivos.

Compatibilidade

A biblioteca exige acesso às portas de I/O x86 e um controlador PS/2 disponível ou emulado.

Compilação

Compile em ambiente freestanding x86, utilizando as opções apropriadas ao kernel.

Testes

Teste teclas especiais, layouts, movimento, botões e scroll em emuladores e hardware.

Recomendações

  • Não bloqueie indefinidamente esperando um byte PS/2.
  • Chame ReadPS2() regularmente.
  • Não confunda caracteres ASCII com scancodes.
  • Considere os limites da tela ao movimentar o cursor.
  • Verifique a disponibilidade de PS/2 no hardware.
  • Confira ps2.h para conhecer os tipos e campos exatos.
  • Teste o driver antes de utilizá-lo em produção.
PS/2 não está presente em todos os computadores modernos. Muitos equipamentos utilizam exclusivamente USB para teclado e mouse. A biblioteca não substitui um driver USB HID.
